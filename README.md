## 📖 Project Overview

This project is a **production-ready style** implementation of the timeless Rock Paper Scissors game. Designed as both a fun demo and a learning resource, it demonstrates clean Python practices, proper game logic, and user experience considerations in a console environment.

Perfect for beginners looking to understand game development fundamentals or recruiters evaluating clean, maintainable code.

## ✨ Features

- **Smart Game Logic**: Accurate win/lose/draw conditions with mapping system
- **Input Validation**: Robust handling of user inputs with helpful feedback
- **Multiple Rounds**: Play as many rounds as you want with score tracking
- **Clean Console UI**: Professional formatting and engaging messages
- **Random AI Opponent**: Unpredictable computer choices using Python's `random` module
- **Score Tracking**: Persistent scoring across rounds in a single session

## 🛠️ Tech Stack

| Technology | Purpose |
