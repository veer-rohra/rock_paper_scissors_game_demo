# 📖 Project Overview

This project is a **production-ready style** implementation of the timeless Rock Paper Scissors game. Designed as both a fun demo and a learning resource, it demonstrates clean Python practices, proper game logic, and user experience considerations in a console environment.

Perfect for beginners looking to understand game development fundamentals or recruiters evaluating clean, maintainable code.

---

# ✨ Features

- ✅ Smart Game Logic with accurate win/lose/draw conditions
- ✅ Input Validation for better user experience
- ✅ Multiple Round Gameplay
- ✅ Clean Console UI
- ✅ Random AI Opponent using Python's `random` module
- ✅ Score Tracking System

# 🚀 Installation

## Prerequisites

- Python 3.6 or higher installed

## Steps

### 1️⃣ Clone the repository

```bash
git clone https://github.com/veer-rohra/rock_paper_scissors_game_demo.git
```

### 2️⃣ Move into the project directory

```bash
cd rock_paper_scissors_game_demo
```

### 3️⃣ Run the game

```bash
python main.py
```

---

# 🎮 How to Play

1. Run the game using:

```bash
python main.py
```

2. Enter one of the following choices:

- `rock`
- `paper`
- `scissors`

3. View the result and enjoy the game!
